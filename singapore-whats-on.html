    Source settings

    These are the websites the daily update searches for events. Maximum 20. Only secure (https) web addresses are accepted.

    To make the daily update use your list: download sources.json and upload it to the main folder of your GitHub repository (same place as events.json). Saving here only keeps a draft in this browser; it does not change the live website. Every refresh reads the current published file, including newly added enabled sites. Alternatively, use Publish source list with the token below to save directly to GitHub and start a refresh. Browser drafts must be published or uploaded before the refresh can use them.

    🔄 Run What's On refresh

    The refresh runs on GitHub (the same job that runs daily). It looks for new events and removes finished ones, then updates the website. It can take a few minutes.

    Open GitHub Actions ↗

    Simple way, no token: in GitHub Actions, click the refresh job on the left, then Run workflow → Run workflow.

    Publish sources or run a refresh (needs a GitHub token)

    Create a “fine-grained personal access token” in GitHub for the EverydayCompass repository only, with Contents: Read and write to publish sources, and Actions: Read and write to start jobs manually, and a short expiry. Paste it below. It is used only for this visit, is never saved, and is cleared when you close this panel. Never put the token inside the html file.
